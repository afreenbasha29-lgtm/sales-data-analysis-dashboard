# 📊 Sales Data Analysis Dashboard

## 📌 Project Overview
This project presents an interactive Excel dashboard built to analyze sales data across different regions, categories, and channels.

## 🔧 Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization
- Slicers (for filtering)

## 📈 Key Features
- Interactive dashboard with filters for Month, Category, and Channel
- Visualization of sales trends and order status
- Analysis of top-performing regions and sales channels

## 💡 Insights
- Identified top-performing sales channels
- Analyzed regional sales distribution
- Evaluated order status trends (Delivered, Cancelled, Returned)
